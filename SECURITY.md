# Security Policy

Golden Apple has no released product or supported version. Do not report suspected vulnerabilities through a public issue. A private disclosure address or GitHub private vulnerability reporting must be configured before the first release; until then, retain details and contact the repository owner through a non-public channel visible on their GitHub profile.

Reports should include affected revision, impact, reproduction prerequisites, minimal proof, and safe contact details. Do not access data you do not own, degrade systems, persist access, or publish exploit details before coordinated resolution.

The planned product treats workspace content as hostile input, gates privileged behavior on explicit consent, keeps secrets out of model context and logs, authenticates local IPC, and defaults to local persistence. This is planned architecture, not a current security guarantee.

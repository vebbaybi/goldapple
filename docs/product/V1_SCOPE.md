# V1 Scope

V1 is a supportable VS Code-first product containing the complete MVP loop plus hardened install/upgrade, signed artifacts, account and device boundaries where justified, configurable model providers, privacy controls, audit export, multiple documented project ecosystems, resilience, accessibility, telemetry opt-in, deletion/reset, troubleshooting, and release/support operations.

V1 remains investigation-first. Any write or execution capability requires a separately reviewed controlled-actions milestone and is not implied by V1. Native applications, broad machine observability, marketplace, network, token, and third-party agent SDK remain future scope.

# Status Mapping

| Status | Evidence threshold | Current use |
| --- | --- | --- |
| AVAILABLE | Supported published artifact and release evidence | None |
| EXPERIMENTAL | Runnable artifact with tests and stated limitations | None |
| IN DEVELOPMENT | Implementation exists on a tracked branch/issue | None |
| PLANNED | Approved and bounded specification | VSIX MVP systems |
| RESEARCH | Open design questions; no delivery commitment | Agent protocol, network, token, controlled autonomy |

Status is a claim about evidence, not enthusiasm. The global project status remains `Phase 0 — foundation in progress` until its review gates close.

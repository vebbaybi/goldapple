01 / The promise

Not another chatbot.
A record of what is true.

Modern development context is scattered across repositories, terminals, logs, package managers, tests, and memory. Golden Apple is designed to connect those fragments into an explainable investigation.

“Why did this application stop working yesterday?”

Every important answer should show its evidence, distinguish fact from inference, and state uncertainty honestly.

04 / Architecture

Local by default.
Bounded by design.

The VS Code client never becomes a universal authority. A local runtime mediates privileged access. Model providers receive only user-approved, minimized context through a replaceable gateway.

05 / Security & privacy

Your machine is not a prompt.

Repository files can contain malicious instructions. Golden Apple treats content as evidence, never authority. Reading a workspace does not grant permission to execute code, use the network, write files, or retain data.

  • Workspace-scoped consentTrust is explicit, revocable, and capability-specific.
  • No silent cloud uploadExternal provider boundaries are visible before transmission.
  • Evidence-grade auditMaterial operations record source, policy, and outcome.
  • Responsible disclosureSecurity reports use a private route, never public issues.

07 / Future research

A network only where a network earns its place.

The proposed Golden Agent Protocol explores portable identity, capability manifests, provenance, reputation, and work receipts. Blockchain is not required for Golden Apple, the MVP, or core local intelligence. No token or network exists.

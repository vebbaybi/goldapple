# `gaxyz` public website package

This is a portable Golden Apple product/developer website intended for later integration into The 1807 web infrastructure. `gaxyz` is a repository-local package name, not the public brand.

It is **not intended for deployment from this repository**. There is no GitHub Pages, hosting, analytics, server, release, or Golden Apple runtime coupling. Golden Apple must never depend on this directory.

Open `index.html` directly or serve this directory with any static file server. The page is dependency-free at runtime except for optional Google Fonts; system fonts provide a graceful fallback.

## Content contract

Repository specification → verified implementation/tests → release evidence → public claim.

All capability labels use `AVAILABLE`, `EXPERIMENTAL`, `IN DEVELOPMENT`, `PLANNED`, or `RESEARCH`. At present the site truthfully identifies the project as foundation-only.

## Original artwork

`assets/golden-apple-city-hero.png` was generated specifically for Golden Apple using OpenAI's built-in image generation. It uses an original cinematic graphic-novel direction and intentionally avoids existing game characters, logos, locations, typography, cover compositions, weapons, and crime imagery. `assets/golden-apple-logo.png` is copied from the user-provided repository asset. Ownership, trademark, and redistribution terms for brand assets remain subject to owner/legal review.

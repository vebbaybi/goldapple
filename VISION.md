# Vision

Golden Apple will make a developer's fragmented machine context explainable as one evidence-backed system. Its destination is a local-first intelligence layer that can observe authorized sources, model their relationships, investigate failures, propose safe responses, verify outcomes, and retain only approved knowledge.

The first proof is deliberately smaller: explain a development failure inside an authorized VS Code workspace using project, Git, dependency, diagnostic, and approved command-output evidence. The long-term vision is directional, not a claim of current capability.

## Invariants

1. User data remains local unless the user knowingly selects an external provider operation.
2. Claims expose evidence, confidence, and epistemic type.
3. Workspace content is untrusted input, including instructions embedded in files.
4. Read access does not imply execute, network, write, or retain permission.
5. An action is not successful until its intended effect is independently verified.
6. Web3 remains optional and cannot determine core product design.

## Success

Golden Apple succeeds when developers can reach a reproducible diagnosis faster without surrendering control of their code, machine, providers, or history.

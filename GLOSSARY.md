# Glossary

**Claim** — A statement in an investigation, typed as observation, inference, hypothesis, or recommendation.

**Evidence** — Immutable or content-addressed reference to an authorized observation, with source, capture time, integrity metadata, and sensitivity.

**Investigation** — A bounded correlation session initiated by a user question or approved trigger.

**Golden Agent** — A proposed interoperable agent with identity, capability, provenance, and policy metadata. Future architecture only.

**GoldenGraph** — The typed relationship model over project entities, events, and evidence; not necessarily a graph database.

**Local runtime** — A user-controlled process that performs privileged local discovery outside the VS Code extension host.

**MVP** — The smallest read-only product proving an evidence-backed development-failure investigation.

**V1** — A supported VS Code-first product containing the MVP loop plus production hardening, account boundaries, provider controls, auditability, and broader supported evidence adapters.

**Work Receipt** — A proposed privacy-preserving record of useful agent work. It is not implemented and is not automatically public or on-chain.

**Workspace authorization** — Explicit, revocable permission to inspect a bounded workspace; distinct from permission to execute, transmit, write, or retain.

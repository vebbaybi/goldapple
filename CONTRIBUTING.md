# Contributing

Golden Apple is in Phase 0. Useful contributions are bounded architectural critiques, threat models, user research, evidence-model analysis, documentation fixes, and test-design proposals. Product implementation requires an accepted ADR and traced requirement.

## Workflow

1. Open an issue describing the problem, boundary, risk, and proposed evidence of success.
2. Keep changes small and update affected requirements, ADRs, tests, and public status.
3. Never include secrets, private repositories, production logs, personal data, or generated credentials.
4. Run supported validation and report exact results.
5. Use Conventional Commit intent where practical; require review before merging.

By contributing, you agree that submitted contributions are licensed under Apache-2.0. See the Code of Conduct and Security Policy.
